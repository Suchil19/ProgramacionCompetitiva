# Instalación de Git

- Git permite a los desarrolladores seguir y gestionar los cambios en el código fuente a lo largo del tiempo. Cada vez que se realizan cambios, se guarda una nueva versión del proyecto, lo que facilita la recuperación de versiones anteriores si es necesario.

![Git](img/git.png)

### Beneficios de Usar Git

- **Historial Completo**: Mantiene un registro completo de todos los cambios realizados en el proyecto, permitiendo a los desarrolladores revisar y revertir cambios si es necesario.

- **Flexibilidad**: Soporta diferentes flujos de trabajo y estilos de desarrollo, desde entornos de desarrollo centralizados hasta distribuidos.

- **Seguridad**:Gracias a su modelo distribuido y sistema de verificación de integridad, Git proporciona un entorno seguro para la gestión de código fuente.

- **Amplia Adopción**: Es una herramienta de código abierto ampliamente adoptada en la industria del software, con una gran cantidad de recursos y soporte disponible.


## Instalar Git en Windows

![Git](/Manuales/InstalacionGit/img/git01.png) 

### Descarga el Instalador de Git
- Ve a la página oficial de Git <a href="https://git-scm.com/downloads/win">Puedes Descargarlo aquí.</a>

### Ejecuta el archivo de instalación

- Una vez descargado, ejecuta el archivo de instalación y sigue las instrucciones del asistente de instalación.

### Configura Git

- Durante la instalación, se te pedirá configurar algunas opciones.
- Puedes dejar las configuraciones en sus valores predeterminados y solo darle click al boton "Next".

### Completa la Instalación

- Finaliza el proceso de instalación y reinicia tu computadora si es necesario.

### Verifica la Instalación

- Abre una ventana de la línea de comandos (cmd) y escribe git --version para verificar que Git se ha instalado correctamente.

## Instalar Git en Mac 

![Git](/Manuales/InstalacionGit/img/git02.png) 

### Instalador Binario de Git

- Descargar el Instalador de Git desde la página oficial de Git <a href="https://sourceforge.net/projects/git-osx-installer/">Puedes Descargarlo aquí.</a>

- Ejecutar el Instalador y seguir las instrucciones.

- Una vez instalado, abre una terminal y verifica la instalación escribiendo:

 ```Python
git --version

```
