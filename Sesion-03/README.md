# Condicionales

## Estructuras de Control
Las condicionales en Python son estructuras de control que permiten ejecutar diferentes bloques de código en función de si una condición específica es verdadera o falsa. Estas estructuras son fundamentales para la toma de decisiones en los programas y se implementan mediante las declaraciones if, elif y else. Aquí tienes una descripción detallada:

## Construir Soluciones
La idea básica es intentar construir una solución paso a paso, eligiendo cada opción posible en cada paso. Si se llega a un punto donde una opción no puede conducir a una solución válida, se retrocede (backtrack) al paso anterior y se intenta con la siguiente opción. Este proceso continúa hasta que se encuentra una solución válida o hasta que se han explorado todas las opciones posibles.

## N Reinas
Un ejemplo clásico de problema que se puede resolver con backtracking es el problema de las N reinas, donde se busca colocar N reinas en un tablero de ajedrez de NxN de manera que ninguna reina se ataque entre sí.
